# Каталог для исходных открытых данных

В этот каталог можно поместить реальные открытые или обезличенные данные,
которые используются для расширения практикума.

Для занятий 1-3 базовые CSV-файлы формируются воспроизводимо в каталоге
`data/processed`. Реальный открытый набор Electric Motor Temperature
рассматривается как источник структуры признаков и может быть добавлен
отдельно при наличии учетной записи Kaggle и соблюдении условий лицензии.
