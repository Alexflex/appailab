# Открытые источники для расширения занятий 7-9

Документ фиксирует источники, которые используются как методические задания
для расширения базовых практик. Полные архивы не загружаются автоматически,
поскольку цель первого этапа - воспроизводимые локальные занятия.

## 1. Partial Discharge Signals in Insulated Power Cables

URL: https://data.mendeley.com/datasets/3mdgxv6zt7.

Назначение: анализ временных сигналов частичных разрядов и аннотаций времени
прихода импульсов. Источник подходит для занятия 7, где студент должен
переходить от временного сигнала к признакам: амплитуде, энергии, числу
импульсов, SNR и спектру.

Риск: аннотации времени прихода являются диагностической информацией. Их нельзя
использовать как обычные признаки без объяснения, поскольку они могут раскрыть
целевую переменную.

## 2. Dataset for New Synthetic Partial Discharge Calibrator

URL: https://zenodo.org/records/8436197.

Назначение: анализ калиброванных импульсов частичных разрядов. Источник
полезен для проверки устойчивости амплитудных и энергетических признаков.

Риск: источник ближе к метрологической задаче, чем к классификации реальных
дефектов изоляции. В отчете нужно явно указать это ограничение.

## 3. pandapower IEEE test networks

URL: https://pandapower.readthedocs.io/en/latest/networks/power_system_test_cases.html.

Назначение: проверка расчетов режима на типовых малых сетях. Источник полезен
для занятий 8-9 как следующий шаг после учебной 6-узловой сети.

Риск: тестовая сеть не является реальным фрагментом энергосистемы. Нельзя
переносить численные пределы без проверки базисных мощностей и параметров.

## 4. IEEE PES Distribution Test Feeders

URL: https://cmte.ieee.org/pes-testfeeders/.

Назначение: анализ распределительных сетей и просадок напряжения.

Риск: для распределительных сетей отношение активного сопротивления к
реактивному часто выше, поэтому DC-приближение может быть менее применимо.

## 5. MATPOWER case archive

URL: https://matpower.org/docs/ref/matpower6.0/menu6.0.html.

Назначение: сравнение AC- и DC-расчетов на стандартных тестовых сетях.

Риск: при переносе case-файла в pandapower нужно проверять базисную мощность,
типы шин, ограничения генераторов и соответствие единиц.

## Минимальное задание студенту

1. Составить паспорт источника.
2. Указать, что является наблюдением или расчетным сценарием.
3. Разделить входные признаки, целевые переменные и диагностические аннотации.
4. Назвать риск утечки данных.
5. Предложить две визуализации и одну метрику качества.
