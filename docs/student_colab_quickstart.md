# Краткая памятка по запуску блокнотов в Google Colab

## 1. Перед началом

1. Убедитесь, что у вас есть учетная запись Google.
2. Откройте `https://drive.google.com` и проверьте доступ к Google Drive.
3. Используйте современный браузер.

## 2. Открытие блокнота

Откройте нужный student-блокнот по Colab-ссылке из `README.md`.

Если Colab-ссылка не открывается, значит GitHub-репозиторий недоступен текущему
пользователю. Войдите в GitHub с выданным доступом или используйте
кафедральный JupyterHub/JupyterLab.

Базовые занятия:

1. Занятие 01 - первичный анализ инженерных данных.
2. Занятие 02 - регрессия коэффициента полезного действия.
3. Занятие 03 - дерево решений для классификации режимов.

Расширенные занятия находятся в `notebooks/external/student/`.

## 3. Обязательное сохранение личной копии

После открытия блокнота выполните:

1. `File -> Save a copy in Drive`.
2. Работайте только в открывшейся личной копии.
3. Переименуйте файл по шаблону:
   `Фамилия_Группа_Занятие_XX.ipynb`.

## 4. Запуск

1. Выполните первую ячейку `COLAB_BOOTSTRAP_APPailab`.
2. Дождитесь сообщения "Среда Google Colab подготовлена".
3. Выполняйте ячейки сверху вниз.
4. В ячейках с `TODO` заполните требуемые параметры.
5. Перед сдачей выполните `Runtime -> Run all`.

Google Colab - облачная среда выполнения Jupyter Notebook. Runtime - среда
выполнения Python-кода. При сбросе runtime необходимо повторно выполнить
первую ячейку.

## 5. Что сдавать

Необходимо подготовить:

1. Выполненный `.ipynb`.
2. PDF-версию выполненного блокнота.
3. Отчет `.md` по шаблону `docs/templates/practice_report_template.md`.

Скачивание `.ipynb`: `File -> Download -> Download .ipynb`.

Создание PDF: `File -> Print -> Save as PDF`.

## 6. Минимальный чек-лист

Перед сдачей проверьте:

1. Блокнот сохранен в Google Drive.
2. Все ячейки выполнены без ошибок.
3. Таблицы и графики отображаются.
4. Параметры в ячейках `TODO` заполнены.
5. Выводы написаны на русском языке в строгом научном стиле.
6. Подготовлены файлы `.ipynb`, `.pdf`, `.md`.

## 7. Типовые ошибки

1. Не выполнена первая ячейка - выполните `COLAB_BOOTSTRAP_APPailab`.
2. Появился `FileNotFoundError` - перезапустите runtime и выполните первую
   ячейку снова.
3. Потеряна сессия - выполните `Runtime -> Run all`.
4. Не сохранены изменения - проверьте, что работаете в копии Google Drive.
