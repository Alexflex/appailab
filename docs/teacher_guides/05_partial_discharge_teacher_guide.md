# Методическое руководство преподавателя. Практическое занятие 5

## Тема

Классификация типа частичных разрядов по PRPD-признакам. Сравнение
логистической регрессии, дерева решений, случайного леса и метода
опорных векторов.

PRPD (Phase Resolved Partial Discharge) - фазово-разрешенное
представление частичных разрядов. SVM (Support Vector Machine), метод
опорных векторов, строит разделяющую поверхность между классами. RBF
(Radial Basis Function), радиальная базисная функция, задает нелинейное
ядро SVM.

## Цель занятия

Научить студентов строить начальную диагностическую классификацию по
признакам частичных разрядов и интерпретировать метрики многоклассовой
классификации с учетом риска пропуска дефектного состояния.

## Наборы данных

1. `data/processed/practice_05_partial_discharge_features.csv` -
   feature-таблица с PRPD-признаками и целевой переменной `defect_class`.
2. `data/processed/practice_05_partial_discharge_diagnostics.csv` -
   производные диагностические величины: `risk_score`,
   `has_partial_discharge`, `high_risk`, фазовые границы кластеров.
3. `data/processed/practice_05_partial_discharge.csv` - полная таблица.

Диагностические столбцы не используются в базовой модели. Особенно важно
не включать `risk_score`, поскольку он является производной риск-оценкой,
связанной с правилом генерации класса.

## Методический сценарий

1. Объяснить, что частичный разряд не является полным пробоем изоляции,
   но может быть диагностическим признаком ухудшения состояния.
2. Разобрать признаки: фазовое положение, кажущийся заряд, число
   импульсов, повторяемость и параметры формы импульса.
3. Показать необходимость масштабирования перед SVM: признаки имеют
   разные физические единицы и разные численные диапазоны.
4. Сравнить модели по accuracy, macro-precision, macro-recall и macro-F1.
5. Обсудить, почему антипример с `risk_score` нельзя включать в отчет как
   основной результат.

## Эталонные ориентиры

При фиксированном `RANDOM_STATE = 20260507` учебный набор является
сбалансированным: по 160 наблюдений на каждый класс `no_pd`, `corona`,
`surface`, `internal`.

Ожидаемый результат для строгих признаков:

| Модель | Accuracy | Macro-F1 |
|---|---:|---:|
| Logistic Regression | 0.98-1.00 | 0.98-1.00 |
| Decision Tree | 0.97-1.00 | 0.97-1.00 |
| Random Forest | 0.98-1.00 | 0.98-1.00 |
| SVM linear | 0.98-1.00 | 0.98-1.00 |

Высокое качество является свойством учебного набора с хорошо разделенными
классами. На реальных PRPD-данных качество обычно ниже из-за шума,
перекрытия дефектов, неоднозначной разметки и влияния измерительной цепи.

## Контрольные вопросы и ориентиры ответа

1. Что такое частичный разряд?  
   Ответ: локальный электрический разряд в части изоляции, не полностью
   перекрывающий изоляционный промежуток.
2. Что показывает PRPD-представление?  
   Ответ: распределение импульсов частичных разрядов по фазе питающего
   напряжения и величине заряда.
3. Почему SVM требует масштабирования?  
   Ответ: расстояния и зазор чувствительны к масштабу признаков; без
   масштабирования признаки с большими численными значениями доминируют.
4. Чем macro-F1 отличается от accuracy?  
   Ответ: macro-F1 усредняет качество по классам и не скрывает слабое
   качество на редком классе.
5. Почему `risk_score` является утечкой?  
   Ответ: это производная диагностическая оценка, построенная из скрытого
   правила разметки, а не независимый измеряемый признак.

## Типовые ошибки студентов

1. Обучение SVM без `StandardScaler`.
2. Использование diagnostics-CSV в качестве признаков.
3. Формальный выбор модели только по accuracy.
4. Отсутствие анализа матрицы ошибок по каждому классу.
5. Утверждение, что модель ставит окончательный технический диагноз.
