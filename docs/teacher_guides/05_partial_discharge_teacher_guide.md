# Методическое руководство преподавателя. Практическое занятие 5

## Тема

Классификация типа частичных разрядов по PRPD-признакам. Сравнение
логистической регрессии, дерева решений, случайного леса и метода
опорных векторов.

PRPD (Phase Resolved Partial Discharge) - фазово-разрешенное
представление частичных разрядов. SVM (Support Vector Machine), метод
опорных векторов, строит разделяющую поверхность между классами. RBF
(Radial Basis Function), радиальная базисная функция, задает нелинейное
ядро SVM.

## Цель занятия

Научить студентов строить начальную диагностическую классификацию по
признакам частичных разрядов и интерпретировать метрики многоклассовой
классификации с учетом риска пропуска дефектного состояния.

## Наборы данных

1. `data/processed/practice_05_partial_discharge_features.csv` -
   feature-таблица с PRPD-признаками и целевой переменной `defect_class`.
2. `data/processed/practice_05_partial_discharge_diagnostics.csv` -
   производные диагностические величины: `risk_score`,
   `has_partial_discharge`, `high_risk`, фазовые границы кластеров.
3. `data/processed/practice_05_partial_discharge.csv` - полная таблица.

Диагностические столбцы не используются в базовой модели. Особенно важно
не включать `risk_score`, поскольку он является производной риск-оценкой,
связанной с правилом генерации класса.

## Термины для обязательного пояснения

1. Partial discharge, частичный разряд - локальный электрический разряд в
   части изоляции, не полностью перекрывающий промежуток между электродами.
2. PRPD (Phase Resolved Partial Discharge) - фазово-разрешенное
   представление частичных разрядов.
3. Apparent charge, кажущийся заряд - измерительная характеристика
   импульса частичного разряда.
4. SVM (Support Vector Machine), метод опорных векторов - классификатор,
   строящий разделяющую поверхность между классами.
5. Margin, зазор - расстояние от разделяющей поверхности до ближайших
   объектов классов.
6. RBF (Radial Basis Function), радиальная базисная функция - нелинейное
   ядро SVM.
7. Macro-F1 - среднее значение F1-меры по классам без учета размера
   класса.

## Математическая основа

Для многоклассовой классификации оценивается функция:

$$
\hat{y} = f(\mathbf{x}),
$$

где \(\mathbf{x}\) - вектор PRPD-признаков, \(\hat{y}\) - предсказанный
класс дефекта. F1-мера для одного класса определяется как:

$$
F1 = \frac{2 \cdot precision \cdot recall}{precision + recall}.
$$

Macro-F1 вычисляется как среднее F1 по всем классам. Это важно, потому
что диагностическая задача не должна скрывать плохое качество на
отдельном классе за высокой общей accuracy.

## Конкретизация задания для студентов

Студент должен выполнить шесть содержательных действий:

1. выбрать безопасные PRPD-признаки без `risk_score`;
2. объяснить необходимость `StandardScaler`;
3. задать параметр `C` для SVM в диапазоне 0.1-10;
4. выбрать модель по macro-F1;
5. описать один тип диагностической ошибки по матрице ошибок;
6. объяснить, почему `risk_score` является утечкой данных.

## Методический сценарий

1. Объяснить, что частичный разряд не является полным пробоем изоляции,
   но может быть диагностическим признаком ухудшения состояния.
2. Разобрать признаки: фазовое положение, кажущийся заряд, число
   импульсов, повторяемость и параметры формы импульса.
3. Показать необходимость масштабирования перед SVM: признаки имеют
   разные физические единицы и разные численные диапазоны.
4. Сравнить модели по accuracy, macro-precision, macro-recall и macro-F1.
5. Обсудить, почему антипример с `risk_score` нельзя включать в отчет как
   основной результат.

## Как объяснять студентам задачу

Основная формулировка для аудитории: студент решает учебную задачу
многоклассовой классификации дефектов по агрегированным PRPD-признакам.
Он не анализирует сырые осциллограммы, а работает с признаками, уже
извлеченными из фазово-разрешенного представления частичных разрядов.

Следует подчеркнуть, что диагностический вывод модели является
предварительным. Он показывает, к какому классу ближе наблюдение по
выбранным признакам, но не заменяет протокол испытаний, калибровку
измерительной цепи и экспертную оценку состояния изоляции.

## Сценарий объяснения новых графиков

1. Учебная PRPD-диаграмма: показать связь фазы питающего напряжения
   `phase_mean_deg` и амплитуды кажущегося заряда `max_charge_pc`.
   Диаграмма нужна для формирования физического образа признаков.
2. Визуальное сравнение классов в координатах `phase_mean_deg` и
   `mean_charge_pc`: объяснить, что разделимость классов на двух
   признаках не гарантирует такой же разделимости в реальных данных.
3. Матрица ошибок: читать по строкам истинный класс, по столбцам прогноз.
   Ошибка между близкими PRPD-образами имеет иной диагностический смысл,
   чем пропуск внутреннего дефекта.
4. Сравнение balanced и imbalanced выборок: balanced означает
   сбалансированную выборку, imbalanced - несбалансированную. Accuracy
   может оставаться высокой, когда macro-F1 ухудшается на редких классах.
5. Учебная граница SVM: использовать только как двумерную иллюстрацию
   принципа разделяющей поверхности. Основная модель работает в
   многомерном пространстве признаков.
6. SVM без масштабирования: это антипример методической ошибки. Без
   `StandardScaler` признаки с крупным численным диапазоном искажают
   расстояния и зазор.

## Эталонные интерпретации

1. При близких значениях accuracy выбирать модель следует по macro-F1,
   потому что эта метрика не скрывает качество на отдельных классах.
2. Если ошибки между `corona` и `surface` появляются чаще, чем другие,
   допустимое объяснение - частичное перекрытие фазовых и амплитудных
   признаков в учебной модели.
3. `risk_score` является утечкой, поскольку это не независимое измерение,
   а производная диагностическая оценка, связанная с правилом разметки.

## Контрольные вопросы и ориентиры ответа

1. Что такое частичный разряд?  
   Ответ: локальный электрический разряд в части изоляции, не полностью
   перекрывающий изоляционный промежуток.
2. Что показывает PRPD-представление?  
   Ответ: распределение импульсов частичных разрядов по фазе питающего
   напряжения и величине заряда.
3. Почему SVM требует масштабирования?  
   Ответ: расстояния и зазор чувствительны к масштабу признаков; без
   масштабирования признаки с большими численными значениями доминируют.
4. Чем macro-F1 отличается от accuracy?  
   Ответ: macro-F1 усредняет качество по классам и не скрывает слабое
   качество на редком классе.
5. Почему `risk_score` является утечкой?  
   Ответ: это производная диагностическая оценка, построенная из скрытого
   правила разметки, а не независимый измеряемый признак.

## Типовые ошибки студентов

1. Обучение SVM без `StandardScaler`.
2. Использование diagnostics-CSV в качестве признаков.
3. Формальный выбор модели только по accuracy.
4. Отсутствие анализа матрицы ошибок по каждому классу.
5. Утверждение, что модель ставит окончательный технический диагноз.
6. Подмена macro-F1 общей accuracy при обсуждении редких дефектов.
7. Использование `risk_score` как "самого сильного" признака без
   понимания утечки данных.

## Критерий зачета

Зачтено: студент выполнил масштабирование, обучил не менее трех
классификаторов, рассчитал accuracy и macro-F1, построил матрицу ошибок и
объяснил антипример утечки.

Частично зачтено: классификация выполнена, но отсутствует содержательный
разбор ошибок или роли масштабирования.

Не зачтено: `risk_score` использован как базовый признак либо отсутствуют
метрики по классам.
