# Руководство по визуализации и пояснениям для занятий 4-6

Документ дополняет методические руководства занятий 4-6 и задает единый
подход к объяснению графиков в аудитории.

## Общие правила

1. Перед графиком преподаватель формулирует вопрос, на который этот график
   должен ответить.
2. После графика студент должен записать один численный факт и один
   инженерный вывод.
3. Diagnostics-CSV используется только для интерпретации или антипримера,
   если это явно указано в блокноте.
4. Высокое значение метрики не считается самостоятельным доказательством
   корректности модели.

## Занятие 4. Тепловое моделирование

Основная визуальная линия:

1. схема теплового баланса показывает причинную цепочку от электрической
   мощности к потерям и нагреву;
2. профили температуры по `profile_id` объясняют тепловую инерцию;
3. график `winding_temp_c` против `total_loss_w` используется только для
   физического пояснения, так как `total_loss_w` находится в diagnostics;
4. график прогноза и остатков показывает, где модель систематически
   ошибается;
5. permutation importance, перестановочная важность, помогает обсудить
   вклад признаков без отождествления с причинностью.

Минимальный вывод студента: указать лучшую модель по RMSE, область
наибольших остатков и причину, по которой `steady_state_temp_c` является
утечкой данных.

## Занятие 5. Частичные разряды

Основная визуальная линия:

1. PRPD-диаграмма формирует образ фазово-разрешенного представления;
2. распределение классов показывает, насколько корректно использовать
   accuracy;
3. матрица ошибок переводит метрики в диагностический смысл;
4. двумерная граница SVM является иллюстрацией принципа разделения;
5. сравнение SVM с масштабированием и без масштабирования демонстрирует
   методическую ошибку.

Минимальный вывод студента: выбрать модель по macro-F1, описать один тип
ошибки и объяснить, почему `risk_score` нельзя считать независимым
измеряемым признаком.

## Занятие 6. Кластеризация режимов

Основная визуальная линия:

1. схема pipeline фиксирует запрет на использование diagnostics до
   обучения;
2. тепловая карта корреляций показывает связанные сенсорные признаки;
3. PCA biplot показывает одновременно объекты и направления признаков;
4. графики inertia и silhouette помогают выбрать число кластеров;
5. профили кластеров переводят численные группы в инженерные описания.

Минимальный вывод студента: выбрать `n_clusters`, описать 2-3 кластера по
профилям признаков и объяснить, почему `true_mode_label`, `mode_id` и
`anomaly_flag` нельзя использовать как входные признаки.

## Типовые ошибки интерпретации

1. Переписывание подписи графика вместо вывода.
2. Выбор модели только по одной метрике.
3. Использование diagnostics-CSV как обычной таблицы признаков.
4. Отождествление важности признака с доказанной физической причинностью.
5. Игнорирование способа разбиения выборки.
6. Интерпретация кластера как окончательного диагноза оборудования.
